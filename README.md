# 架空城市交通绘图台

无需联网或安装依赖的本地单页工具，用来绘制架空城市的道路、公交/轨道线路、站点、地名及路名。

## 使用

直接双击 `index.html`，在浏览器中打开即可。

- **道路 / 地铁**：单击逐点绘制，绘制过程中可随时将“下一段”切换为直线或曲线，右键结束。新地铁线路点击既有站点时会精确经过该站。
- **道路等级**：可选高速公路、一级道路、二级道路或小路；等级会设置推荐线宽和颜色。道路名称会按道路长度等距重复显示，并沿道路方向排列。
- **道路层级**：绘制中用 `↑`、`↓` 调整下一段层级。`0` 为地面，正数为逐层上跨，负数为逐层下钻；可创建 `+1`、`+2` 等多层桥梁。同层道路交叉会形成路口，相邻道路段改变层级会形成可通行匝道。
- **公交线路**：只可点击已有道路，工具会沿道路网络自动连接每一个落点。交叉位置可用 `↑`、`↓` 选择要吸附的层级；公交可经过同层路口和匝道，但不会在没有匝道的不同层交叉点转向。
- **地铁站点**：使用“站点”工具点击既有地铁线，新站会吸附并记录所属线路，但不会改变线路的控制点或曲线形状；不能在空白处独立放置站点。
- **地铁层级与冲突**：地铁与道路一样可逐段使用 `↑`、`↓` 改变层级。地面层地铁不能与地面道路相交，同层地铁不能相交；在既有站点处接入是允许的。冲突段不会落点，并会显示原因。
- **建筑 / 区域**：逐点绘制多边形，右键闭合后输入自定义名称；可在右侧修改名称和颜色。
- **文字**：单击落点后输入名称。
- **选择**：点选对象并在右侧编辑名称、颜色、宽度等；`Delete` 可删除。
- 鼠标滚轮以指针为中心缩放；右侧视图栏提供缩放滑杆、加减缩放、方向移动、100% 重置和适配全部内容。任意绘图工具下均可按住空格拖动画布。视图快捷键：`+` 放大、`-` 缩小、`0` 重置、`Home` 适配全部内容。
- 正层级桥梁按数字由低到高叠放，较高桥面会覆盖较低桥面；负层级隧道按数字分层并以虚线、入口标区分。
- “保存”存入当前浏览器本地储存；“导出 JSON”可备份或用于其他浏览器导入。

快捷键：`V` 选择、`R` 道路、`B` 公交、`M`（或 `T`）地铁、`S` 站点、`G` 建筑、`A` 区域、`L` 文字、`E` 删除。绘制道路或地铁时，`C` 选择曲线段，`X` 选择直线段，`↑`、`↓` 调整层级。

## 第一次更新：性能、缩放与线路延长

- 地图最小缩放比例由 25% 扩展到 10%，网格背景范围同步扩大。
- 新增曲线采样缓存、道路空间索引、公交路网缓存和优先队列寻路，降低大型地图中公交预览的重复计算。
- 地图仅渲染当前视口及周边预加载区域；平移和缩放使用动画帧限流，低缩放比例自动减少名称细节。
- 道路与地铁按线路和层级合并 SVG 路径，减少地图对象增多后的 DOM 数量。
- 新建地铁站自动继承所在线路的颜色。
- 公交和地铁可从既有线路的起点或终点继续延长；之后道路也加入了同样的双端延长功能。选中对象后，在右侧使用“起点”或“终点”按钮开始，右键完成。

## 第二次更新：撤销、边界调整与线路重画

- 顶部新增撤销和重做按钮，支持 `Ctrl+Z`、`Ctrl+Y` 和 `Ctrl+Shift+Z`；当前页面会话保存最近 50 次有效修改。
- 新增、删除、样式修改、线路延长、线路重画和边界调整均可撤销或重做。
- 建筑和区域支持拖动边界顶点。向外拖动可延伸区域，向内拖动可缩减区域；可完成或取消本次调整。
- 道路、公交和地铁支持重画起点侧或终点侧。选择需要替换的一侧后，在线路上点击截断点，重新绘制并右键完成；按 `Esc` 取消。
- 公交重画部分仍沿既有道路寻路；地铁重画部分继续执行道路、层级、站点和同层线路冲突检查。

## 第三次更新：中间段编辑与名称样式

- 道路、公交和地铁新增“重画中间段”。先在原线路上点击修改起始点，再自由绘制新的中间路线；最后点击原线路上的回接位置固定终点，再单击右键完成，两侧未修改线路保持不变。
- 中间段不再预选第二截断点，也不会在右键时自动补线。公交回接仍使用道路寻路；地铁在回接后根据实际保留区段统一检查同层交叉冲突。
- 道路名称减少重复标记数量，并根据缩放比例缩短过长的显示文字；地图数据中的完整道路名称不会被修改。
- 站点、地名文字、建筑名称、区域名称以及公交/地铁线路名称均可直接拖动调整显示位置。
- 公交和地铁线路名称改为可配置名称牌，支持胶囊、方牌、圆牌和纯文字四种形状，并可修改背景颜色、文字颜色、字号及位置。
